## SVG Icon Generator

A CLI utility that converts and optimizes FontAwesome icons into SVG icon sets for web projects.

### Installation

```bash
pip install svg-icon-generator
```

### Usage

```bash
svg-icon-generator [OPTIONS] COMMAND [ARGS]...
```

### Example

```bash
svg-icon-generator generate --icons 'fa-camera,fa-heart' --output icons.svg
```
